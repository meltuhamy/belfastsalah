# Preview images

Generated by `.github/workflows/previews.yml`. Do not merge this branch, and
do not edit it: every update replaces it with a single new commit.

- `pr-<number>/<commit>/` holds the screenshots in the preview comment on
  that pull request. Only the latest commit's are kept.
- `master/` holds the latest build of `master`, at full size.

Folders for pull requests closed without merging are deleted at once, and
those for merged ones after six months.
